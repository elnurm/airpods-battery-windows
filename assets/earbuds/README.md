# Widget illustrations

These AI-generated transparent illustrations were created for this project using the built-in image generation tool. They are visual representations, not official Apple assets. The Pro generations share one illustration; AirPods 1 and 2 also share one. Filenames map to the styles in WidgetArtwork.cs. PNGs are embedded in the executable so the widget does not fetch artwork from the internet.

The generated transparent sprite sheet was split into its four columns, trimmed to alpha bounds, and resized for the widget. The right-earbud image is mirrored at render time.

## Generation prompt

A transparent sprite sheet for a tiny AirPods battery widget. Exactly four single white earbuds in four equal-width columns, aligned at same height, each fully contained in its own column with large transparent gutters. No labels, no text, no rings, no cases, no shadows on the ground, genuinely transparent background. Premium clean photorealistic 3D product rendering with soft silver modeling, all stems down and earpieces facing left. Column 1 AirPods 1/2 classic long narrow stem, hard open-ear head, no silicone. Column 2 AirPods 3 shorter thicker stem bulbous open-ear head, no silicone. Column 3 AirPods 4 compact narrower open-ear head short stem, no silicone. Column 4 AirPods Pro short stem with clearly visible silicone ear tip and dark oval vent. Accurate distinct proportions. Each entire earbud fits inside its quarter of the image, do not overlap columns. Landscape composition.
