# Credits

AirPods Battery for Windows is an independent community project by Elnur Mammadov.

The battery parser was implemented using publicly documented Apple BLE proximity-pairing fields, notably [stuffz/airpods](https://github.com/stuffz/airpods), its [BLE notes](https://github.com/stuffz/airpods/blob/main/docs/ble.md), and [model/field reference](https://github.com/stuffz/airpods/blob/main/src/aap/proximity.hpp). Those notes also credit earlier community reverse-engineering work. No upstream application binaries, icon packs, or libraries are bundled.

The earbud illustrations and mint app icon are original vector artwork generated by Artwork.cs. They are included under this project's MIT license.
